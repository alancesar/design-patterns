# Enterprise Integration Patterns

Catálogo pessoal baseado nos [Messaging Patterns](https://www.enterpriseintegrationpatterns.com/patterns/messaging/) do site Enterprise Integration Patterns, de Gregor Hohpe e Bobby Woolf, que resume o livro *Enterprise Integration Patterns* (2003). Os Conversation Patterns do site ficam fora do escopo. Cada padrão tem descrição, problemas que resolve, quando usar, trade-offs, etiquetas (pilares do Well-Architected Framework) e um diagrama Mermaid.

Padrões marcados com ★ são compartilhados com outro catálogo: este catálogo aponta para o documento original, revisado com o conteúdo desta fonte.

Total: 65 padrões em 7 grupos. Etiquetas: Pilares do Well-Architected Framework.

| [File Transfer](./integration-styles/file-transfer.md) | Em File Transfer, cada aplicação produz arquivos com as informações que outras aplicações precisam e consome arquivos gerados pelas demais. | [`Cost Optimization`](/tags/cost-optimization) [`Operational Excellence`](/tags/operational-excellence) |

| [Remote Procedure Invocation](../microservices/communication-styles/remote-procedure-invocation.md) ★ | Remote Procedure Invocation (RPI) é o estilo de comunicação em que um cliente envia uma requisição a um serviço usando um protocolo síncrono de requisição/resposta, como se estivesse invocando um procedimento remoto. | [`Reliability`](/tags/reliability) [`Performance Efficiency`](/tags/performance-efficiency) [`Operational Excellence`](/tags/operational-excellence) |
| [Messaging](../microservices/communication-styles/messaging.md) ★ | No padrão Messaging, os serviços se comunicam trocando mensagens por canais de mensagens, de forma assíncrona. | [`Reliability`](/tags/reliability) [`Performance Efficiency`](/tags/performance-efficiency) [`Operational Excellence`](/tags/operational-excellence) |

## Messaging Channels (10) {#messaging-channels}

| Padrão | Resumo | Etiquetas |
| --- | --- | --- |

| [Publish-Subscribe Channel](../../cloud/azure/messaging/publisher-subscriber.md) ★ | O padrão Publisher-Subscriber (pub/sub) permite que uma aplicação anuncie eventos de forma assíncrona a vários consumidores interessados, sem conhecer quem são eles. | [`Reliability`](/tags/reliability) [`Security`](/tags/security) [`Cost Optimization`](/tags/cost-optimization) [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |

| [Invalid Message Channel](./messaging-channels/invalid-message-channel.md) | O Invalid Message Channel é um canal separado para onde o receptor desvia as mensagens que recebeu mas não consegue entender ou processar, por exemplo por formato incorreto, campos ausentes ou conteúdo que viola o contrato esperado. | [`Reliability`](/tags/reliability) [`Operational Excellence`](/tags/operational-excellence) |

| [Guaranteed Delivery](./messaging-channels/guaranteed-delivery.md) | O Guaranteed Delivery faz o sistema de mensageria tornar as mensagens persistentes, de modo que não se percam se o próprio sistema falhar. | [`Reliability`](/tags/reliability) [`Cost Optimization`](/tags/cost-optimization) |
| [Channel Adapter](./messaging-channels/channel-adapter.md) | O Channel Adapter conecta uma aplicação que não sabe enviar nem receber mensagens ao sistema de mensageria. | [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |

| [Aggregator](./message-routing/aggregator.md) | O Aggregator é um filtro com estado que fica entre o fluxo de mensagens de entrada e a próxima etapa. | [`Reliability`](/tags/reliability) [`Performance Efficiency`](/tags/performance-efficiency) |

| [Scatter-Gather](./message-routing/scatter-gather.md) | O Scatter-Gather envia uma requisição a vários destinatários e usa um Aggregator para coletar as respostas e combiná-las em uma só. | [`Performance Efficiency`](/tags/performance-efficiency) [`Reliability`](/tags/reliability) |
| [Routing Slip](./message-routing/routing-slip.md) | O Routing Slip resolve o caso em que uma mensagem deve passar por uma sequência de etapas que não é fixa e pode variar de uma mensagem para outra. | [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |
| [Process Manager](./message-routing/process-manager.md) | O Process Manager é um coordenador central que mantém o estado de uma sequência de etapas e decide o próximo passo com base nos resultados até o momento. | [`Reliability`](/tags/reliability) [`Operational Excellence`](/tags/operational-excellence) |
| [Message Broker](./message-routing/message-broker.md) | O Message Broker coloca um intermediário central entre remetentes e receptores. | [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |

## Message Transformation (7) {#message-transformation}

| Padrão | Resumo | Etiquetas |
| --- | --- | --- |
| [Message Translator](./message-transformation/message-translator.md) | O Message Translator é um componente (um filtro no estilo Pipes and Filters) colocado entre dois participantes de uma integração para converter o formato de uma mensagem em outro. | [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |
| [Envelope Wrapper](./message-transformation/envelope-wrapper.md) | O Envelope Wrapper envolve os dados de uma aplicação em um "envelope" que atende aos requisitos da infraestrutura de mensageria e, no destino, remove esse envelope para devolver os dados originais. | [`Security`](/tags/security) [`Operational Excellence`](/tags/operational-excellence) |
| [Content Enricher](./message-transformation/content-enricher.md) | O Content Enricher é um transformador especializado que completa uma mensagem com dados que o destinatário precisa e que o remetente não enviou. | [`Operational Excellence`](/tags/operational-excellence) [`Performance Efficiency`](/tags/performance-efficiency) |
| [Content Filter](./message-transformation/content-filter.md) | O Content Filter remove de uma mensagem os campos que o destinatário não precisa, entregando uma versão mais simples e enxuta. | [`Security`](/tags/security) [`Performance Efficiency`](/tags/performance-efficiency) |
| [Claim Check](../../cloud/azure/messaging/claim-check.md) ★ | O padrão Claim Check separa o armazenamento do conteúdo (payload) da entrega da mensagem. | [`Reliability`](/tags/reliability) [`Security`](/tags/security) [`Cost Optimization`](/tags/cost-optimization) [`Performance Efficiency`](/tags/performance-efficiency) |
| [Normalizer](./message-transformation/normalizer.md) | O Normalizer processa mensagens semanticamente equivalentes que chegam em formatos diferentes e as converte para um único formato comum. | [`Operational Excellence`](/tags/operational-excellence) [`Reliability`](/tags/reliability) |
| [Canonical Data Model](./message-transformation/canonical-data-model.md) | O Canonical Data Model define um formato de dados comum, independente de qualquer aplicação, que passa a ser a "língua franca" da integração. | [`Operational Excellence`](/tags/operational-excellence) [`Reliability`](/tags/reliability) |

| [Message Dispatcher](./messaging-endpoints/message-dispatcher.md) | Message Dispatcher coordena vários consumidores de um mesmo canal. | [`Performance Efficiency`](/tags/performance-efficiency) [`Reliability`](/tags/reliability) |
| [Selective Consumer](./messaging-endpoints/selective-consumer.md) | Selective Consumer é um consumidor que filtra as mensagens do canal e aceita somente as que atendem a seus critérios. | [`Performance Efficiency`](/tags/performance-efficiency) [`Cost Optimization`](/tags/cost-optimization) |
| [Durable Subscriber](./messaging-endpoints/durable-subscriber.md) | Durable Subscriber é um assinante de um Publish-Subscribe Channel cuja assinatura sobrevive à sua desconexão. | [`Reliability`](/tags/reliability) |
| [Idempotent Receiver](../../cloud/azure/messaging/idempotent-consumer.md) ★ | O padrão Idempotent Consumer projeta consumidores de mensagens de forma que processar a mesma mensagem mais de uma vez produza exatamente o mesmo efeito que processá-la uma única vez. | [`Reliability`](/tags/reliability) |
| [Service Activator](./messaging-endpoints/service-activator.md) | Service Activator fica entre o canal de mensageria e um serviço da aplicação. | [`Operational Excellence`](/tags/operational-excellence) [`Reliability`](/tags/reliability) |
