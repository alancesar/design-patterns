# Design Patterns

A personal collection of design patterns, organized by **domain** and, within each domain, by source **catalog**. Each pattern has a description, the problems it solves, when to use it, trade-offs, tags, and a Mermaid diagram.

<CatalogCards />

## Domains

- **[Coding](/coding):** Class and object design.
- **[Application](/application):** Internal application structure and domain modeling (layers, persistence, DDD).
- **[Architecture](/architecture):** System architecture (architectural styles, distribution, integration, consistency, and concurrency).
- **[Cloud](/cloud):** Cloud and container applications and operations.
- **[AI](/ai):** Systems built with LLMs and AI agents.
